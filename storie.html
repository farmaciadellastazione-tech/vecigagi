Proponi una storia

Conosci una lingua o un dialetto non ancora presente (o vuoi arricchire quelli già qui)? Compila la scheda con il testo e la traduzione italiana frase per frase: alla fine ottieni un file JSON nello stesso formato usato internamente per pubblicare le storie, pronto per essere valutato e integrato.
